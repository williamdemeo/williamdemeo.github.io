## UACalc at the Jython Command Line

+ The [UACalc_CLI github repository](https://github.com/UACalc/UACalc_CLI) has instructions for configuring your machine to support a command line interface (CLI) with the [Universal Algebra Calculator (UACalc)](http://uacalc.org).

+ [This post](/computing/uacalc/command-line-examples) gives an example showing how to exploit the Jython interface to the UACalc to study properties of large collections of algebraic structures.
