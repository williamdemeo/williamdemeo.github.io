The [IEPost GitHub repository][] contains a draft of the article
[Interval enforceable properties of finite groups][], to appear in *Communications in Algebra*.

<!-- more -->

The paper has been accepted and is in the final review stage. It should appear in print sometime in 2014.
The original submission is available in the file [DeMeo-IEProps-rev1.pdf][]. The latest revision is in the tex directory.

For questions, comments, or suggestions please [submit an issue][].

Thanks for your interest in this work!
