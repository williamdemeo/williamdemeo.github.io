## 2020

+ [European Online CSP Seminar 2020](https://csp-seminar.org/) - An [overview](https://gitpitch.com/UniversalAlgebra/hom-csp?grs=gitlab#/1) of recent work on bounding the number of homomorphisms into general structures, appearing in [our latest paper (arXiv link)](https://arxiv.org/abs/2010.04958).

+ [Völs am Schlern](https://goo.gl/maps/ar3oAZ1xAy3Wg7KM8) - An [overview of some tools for algebra research](./talks/vols/index.md) on 25 Sep 2020.

+ [Denver](https://goo.gl/maps/eVGao4jFVgYNFkYZ6) - An [early version of the UALib documentation](../agda-ualib/index.html) used in my talk at the [2020 Joint Mathematics Meetings of the AMS](https://jointmathematicsmeetings.org/meetings/national/jmm2020/2245_program_ss56.html#title), where I briefly introduced the [Agda Universal Algebra Library (UALib)](https://ualib.org). 

  - The latest [UALib documentation](https://ualib.org) is available from [ualib.org](https://ualib.org).
  - the latest [UALib source code](https://gitlab.com/ualib/ualib.gitlab.io) is available from [gitlab.com/ualib/ualib.gitlab.io](https://gitlab.com/ualib/ualib.gitlab.io).
